Tier 4: Autonomous Engineering Intelligence Agent & Claim Classification
Agent Orchestrator gain.agent.*
AgentGateway Context & Budget

Enforces plan step limits (max 10), token budgets, correlation tracking (request_id, investigation_id), principal authorization.

InvestigationPlanner Methodology Engine

Constructs deterministic multi-step plans for Flow Health, AI Impact, DORA assessment, and work tracking.

PolicyGuard Security Gate

Detects prompt injections, forbids mutation/push operations, enforces zero-LLM calculation boundaries.

Tool Router & Failure Isolation gain.agent.router
Primary: GAIN MCP Server Authoritative

Dispatches to governed analytical tools. Never falls back to ad-hoc LLM reasoning if service is offline.

Secondary: GitHub MCP Interface Operational Fallback

Read-only operations for repository metadata, recent commits, workflow run status. Graceful degradation when offline.

Circuit Breaker: MCP errors raise GainMcpUnavailableError rather than calculating metrics heuristically.
7-Tier Claim Classification EvidenceSynthesizer
1. Observed Verbatim raw GitHub telemetry records
2. Derived Deterministic mathematical metrics
3. Associated Statistical cohort correlation (AI delta)
4. Attributed Causal relationship (requires evidence)
5. Modeled Parameterized projections (AI ROI)
6. Assumed Benchmark baseline values ($85/hr wage)
7. Unknown Missing telemetry or unverified assertions
LLMGateway: Synthesis restricted to evidence packages. Zero halluncination of metrics permitted.

1. Source of Truth

GitHub telemetry remains immutable ground truth. Raw responses are stored losslessly in JSONL format before any domain transformation.

2. Zero-LLM In Math

All metric computations (Cycle Time, Monthly Stats, DORA, AI ROI) are pure Python deterministic algorithms explicitly cataloged and versioned.

3. Transport Independence

Canonical domain models expose zero GraphQL artifacts (cursors, pageInfo, connections), isolating analytics from upstream protocol shifts.

4. Claim Traceability

All agent findings are tagged with one of 7 claim classifications (Observed, Derived, Associated, etc.) backed by verifiable evidence.
