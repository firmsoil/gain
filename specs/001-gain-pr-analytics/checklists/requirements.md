# Requirements Quality Checklist

- [ ] Each requirement expresses observable behavior.
- [ ] Each core metric has a stable ID/version.
- [ ] Every metric maps to actual GitHub API fields.
- [ ] Lifecycle time is not labeled coding time.
- [ ] Unsupported DORA metrics are explicitly marked as requiring additional data.
- [ ] API pagination is fully specified.
- [ ] Rate-limit behavior is specified.
- [ ] Backfill and incremental synchronization are distinct.
- [ ] Bot handling is explicit.
- [ ] Data-quality failures are visible.
- [ ] Responsible-use restrictions are explicit.
- [ ] Acceptance criteria are testable.
