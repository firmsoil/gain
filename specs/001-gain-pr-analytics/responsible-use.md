# Responsible Use

## Intended use
- system-level engineering flow improvement
- repository/team process diagnostics
- leadership trend analysis
- empirical evaluation of delivery improvements

## Prohibited/default-disallowed use
- compensation decisions based solely on GAIN
- employee ranking by PR volume
- using lines changed as a productivity score
- inferring individual effort from cycle time
- using metrics without sample-size/context controls

## Principles
Metrics are signals, not verdicts. Context, complexity, service criticality, operating model, and team topology matter. GAIN should surface distributions and trends before point estimates and should provide drill-downs with interpretation warnings.
