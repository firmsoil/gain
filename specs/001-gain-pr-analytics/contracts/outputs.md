# Output Contracts

## canonical_pull_requests
One row per canonical PR version/current state.

## metric_observations
One row per metric observation, identified by metric ID/version, grain, time, and entity.

## synchronization_report
Run-level counts, API usage, errors, retries, checkpoints, and scope.

## data_quality_report
Rule ID, severity, affected object count, sample identifiers, and disposition.

## executive_kpis
Curated, aggregate-only KPI set with metric IDs and versions.
